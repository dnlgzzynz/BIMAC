## Uso de las Plantillas

### LEED Checklist

1. Copiar plantilla para el proyecto específico
2. Completar información del proyecto
3. Revisar cada crédito y marcar aplicabilidad
4. Asignar responsables por categoría
5. Actualizar conforme avanza el diseño
6. Documentar evidencia requerida

### EDGE Checklist

1. Registrar proyecto en EDGE App
2. Completar estrategias por categoría
3. Calcular ahorros porcentuales
4. Verificar cumplimiento de metas (≥20%)
5. Preparar documentación para auditoría

---

## Comparación de Certificaciones

| Aspecto | LEED | EDGE |
|---------|------|------|
| **Origen** | USGBC (USA) | IFC/World Bank |
| **Enfoque** | Integral (sitio, agua, energía, materiales, IEQ) | Eficiencia (energía, agua, materiales) |
| **Complejidad** | Alta | Media |
| **Costo** | Alto | Bajo-Medio |
| **Mercado** | Global, premium | Mercados emergentes |
| **Herramienta** | LEED Online | EDGE App (gratuita) |
