# BIMAC

**BIM + AI + Construction**

Ecosistema de conocimiento, herramientas y automatización para la industria AEC (Arquitectura, Ingeniería y Construcción).

---

## Sobre el Proyecto

BIMAC integra tres pilares fundamentales:

```
BIMAC = Building Information Modeling
      + Artificial Intelligence
      + Advanced Construction Management
```

Este repositorio centraliza recursos, scripts, plantillas y documentación para optimizar flujos de trabajo en proyectos de construcción e infraestructura.

---

## Especialidades

| Área | Enfoque |
|------|---------|
| **Dirección de Construcción** | Planeación, coordinación multidisciplinaria, control de costo y plazo |
| **BIM Management** | Procesos 3D-7D, ISO 19650, interoperabilidad |
| **Consultoría TI para AEC** | Integración de software, APIs, automatización |
| **IA Aplicada a AEC** | Prompts, agentes inteligentes, análisis de datos BIM |
| **Sustentabilidad** | LEED, EDGE, WELL, BOMA BEST |

## Stack Tecnológico

### Modelado BIM / CAD / 3D

| Herramienta | Uso |
|-------------|-----|
| Revit | Modelado arquitectónico y MEP |
| Civil 3D | Infraestructura y topografía |
| Rhino + Grasshopper | Diseño paramétrico |
| Navisworks | Coordinación y clash detection |
| Blender / Twinmotion | Visualización |

### Coordinación y 4D

- Synchro 4D
- BIMcollab ZOOM

### Automatización

- **n8n** (self-hosted) — Orquestación de workflows
- **PyRevit** — Automatización en Revit
- **Docker** — Contenedorización

### Productividad

- Notion / Obsidian / Airtable

### IA / LLM

- Perplexity / NotebookLM / LM Studio
