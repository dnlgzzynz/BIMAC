## Cómo Usar Esta Biblioteca

### Estructura de un Prompt Efectivo

```
CONTEXTO:   [Tipo de proyecto, fase, disciplina]
ROL:        [Especialidad requerida del asistente]
TAREA:      [Acción específica a realizar]
FORMATO:    [Estructura esperada del output]
RESTRICCIONES: [Limitaciones, estándares a seguir]
EJEMPLOS:   [Referencias si aplica]
```

### Niveles de Complejidad

| Nivel | Descripción | Uso |
|-------|-------------|-----|
| **Básico** | Tareas simples y directas | Consultas rápidas |
| **Intermedio** | Análisis y síntesis | Reportes, revisiones |
| **Avanzado** | Razonamiento complejo | Estrategia, optimización |

## Índice de Prompts

### Modelado BIM
- Revisión de modelo por disciplina
- Validación de nomenclatura
- Análisis de warnings de Revit
- Sugerencias de organización de vistas

### Coordinación
- Clasificación de interferencias
- Priorización de issues BCF
- Redacción de descripción de clash
- Análisis de impacto de cambios

### Cuantificación (5D)
- Extracción de cantidades por sistema
- Comparación de presupuesto vs modelo
- Análisis de variaciones
- Generación de reportes de cantidades

### Documentación
- Redacción de especificaciones
- Generación de minutas de reunión
- Descripciones de entregables
- Resúmenes ejecutivos

### Sustentabilidad
- Análisis de créditos LEED
- Evaluación de estrategias EDGE
- Recomendaciones de eficiencia
- Checklist de certificación

## Contribuir

Al agregar nuevos prompts:

1. Usar la estructura estándar (Contexto, Rol, Tarea, Formato, Restricciones)
2. Incluir ejemplo de uso
3. Indicar nivel de complejidad
4. Agregar al índice correspondiente
