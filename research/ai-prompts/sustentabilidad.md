# Prompts de Sustentabilidad

---

## 1. Análisis de Créditos LEED

**Nivel:** Avanzado

```
CONTEXTO: Estoy evaluando qué créditos LEED [VERSIÓN] son alcanzables para el proyecto.

INFORMACIÓN DEL PROYECTO:
- Tipo: [oficinas/residencial/retail/educación]
- Ubicación: [ciudad, zona climática]
- Superficie: [m²]
- Presupuesto para sustentabilidad: [$ o %]
- Nivel objetivo: [Certified/Silver/Gold/Platinum]

CARACTERÍSTICAS ACTUALES DEL DISEÑO:
[Listar estrategias ya incorporadas]

ROL: Actúa como consultor LEED AP con experiencia en proyectos similares.

TAREA:
1. Evaluar cada categoría LEED y estimar puntos alcanzables
2. Identificar créditos "fáciles" (bajo costo, alto impacto)
3. Identificar créditos difíciles o no aplicables
4. Recomendar estrategias para alcanzar nivel objetivo
5. Estimar costo-beneficio de créditos opcionales

FORMATO: Tabla por categoría + recomendaciones priorizadas

CATEGORÍAS LEED:
- Location & Transportation
- Sustainable Sites
- Water Efficiency
- Energy & Atmosphere
- Materials & Resources
- Indoor Environmental Quality
- Innovation
- Regional Priority
```

## 2. Checklist de Prerrequisitos LEED

**Nivel:** Intermedio

```
CONTEXTO: Necesito verificar que el proyecto cumple con los prerrequisitos obligatorios de LEED [VERSIÓN].

TIPO DE PROYECTO: [BD+C / ID+C / O+M / Homes]
CATEGORÍA: [New Construction / Core & Shell / Schools / etc.]

INFORMACIÓN DISPONIBLE:
[Listar documentos y datos disponibles del proyecto]

TAREA: Genera un checklist de prerrequisitos que incluya:
1. Cada prerrequisito obligatorio
2. Requisito específico a cumplir
3. Evidencia/documentación necesaria
4. Estado actual (cumple/no cumple/en proceso)
5. Responsable de cada uno
6. Acciones pendientes

FORMATO: Tabla de verificación con estatus

RESTRICCIONES:
- Incluir TODOS los prerrequisitos (no solo los ambientales)
- Indicar fechas límite para documentación
```

## 3. Evaluación de Estrategias EDGE

**Nivel:** Intermedio

```
CONTEXTO: Quiero evaluar si el proyecto puede obtener certificación EDGE.

INFORMACIÓN DEL PROYECTO:
- Tipo: [residencial/oficinas/retail/hoteles/hospitales/educación]
- Ubicación: [país, ciudad]
- Superficie: [m²]
- Clima: [descripción]

DISEÑO BASE (sin estrategias de eficiencia):
[Describir características estándar]

ESTRATEGIAS CONSIDERADAS:
[Listar medidas de eficiencia propuestas]

TAREA:
1. Verificar que cumple umbral mínimo (20% ahorro en energía, agua, materiales)
2. Estimar % de ahorro por cada estrategia
3. Calcular ahorro total por categoría
4. Identificar estrategias faltantes para llegar a 20%
5. Recomendar medidas costo-efectivas adicionales

FORMATO: Tabla de estrategias con impacto estimado + resumen de cumplimiento

CATEGORÍAS EDGE:
- Energía (kWh/m²/año)
- Agua (litros/persona/día)
- Materiales (energía embebida)
```

## 4. Análisis de Confort WELL

**Nivel:** Avanzado

```
CONTEXTO: Estamos considerando certificación WELL [v2] para el proyecto.

TIPO DE ESPACIO: [oficinas/residencial/retail/restaurante/educación]
OCUPANTES ESTIMADOS: [número]
HORARIO DE OPERACIÓN: [horas]

CARACTERÍSTICAS DEL DISEÑO:
- Iluminación: [natural/artificial, niveles]
- Ventilación: [tipo, tasas]
- Acústica: [tratamientos]
- Materiales: [tipos principales]
- Áreas de bienestar: [gimnasio, áreas verdes, etc.]

TAREA:
1. Evaluar potencial en cada concepto WELL
2. Identificar features alcanzables con diseño actual
3. Recomendar mejoras para features adicionales
4. Estimar nivel alcanzable (Bronze/Silver/Gold/Platinum)
5. Listar requerimientos de verificación y monitoreo

CONCEPTOS WELL:
- Air (Aire)
- Water (Agua)
- Nourishment (Nutrición)
- Light (Luz)
- Movement (Movimiento)
- Thermal Comfort (Confort térmico)
- Sound (Sonido)
- Materials (Materiales)
- Mind (Mente)
- Community (Comunidad)

FORMATO: Análisis por concepto con puntuación estimada
```

## 5. Recomendaciones de Eficiencia Energética

**Nivel:** Intermedio

```
CONTEXTO: Necesito recomendaciones para mejorar la eficiencia energética del proyecto.

TIPO DE EDIFICIO: [tipo]
UBICACIÓN: [ciudad, clima]
SUPERFICIE: [m²]

CONSUMOS PRINCIPALES:
- HVAC: [% estimado]
- Iluminación: [%]
- Equipos: [%]
- Otros: [%]

DISEÑO ACTUAL:
[Describir sistemas actuales]

PRESUPUESTO DISPONIBLE: [$ para mejoras]

TAREA:
1. Identificar oportunidades de ahorro por sistema
2. Priorizar por ROI (retorno de inversión)
3. Estimar ahorro energético y económico
4. Recomendar tecnologías específicas
5. Calcular período de recuperación

FORMATO: Tabla de oportunidades con análisis costo-beneficio

RESTRICCIONES:
- Considerar disponibilidad local de tecnologías
- Incluir opciones pasivas y activas
- Indicar si requiere cambios en diseño arquitectónico
```

## 6. Comparativa de Materiales Sustentables

**Nivel:** Intermedio

```
CONTEXTO: Necesito evaluar opciones de materiales sustentables para [APLICACIÓN].

OPCIONES A COMPARAR:
1. [Material/producto A]
2. [Material/producto B]
3. [Material/producto C]

CRITERIOS DE EVALUACIÓN:
- Contenido reciclado
- Materiales regionales
- Emisiones VOC
- Durabilidad
- Costo
- Disponibilidad
- Certificaciones (EPD, HPD, Declare, etc.)

TAREA:
1. Comparar cada opción en todos los criterios
2. Asignar puntuación ponderada
3. Identificar contribución a créditos LEED/WELL
4. Recomendar opción óptima
5. Indicar alternativas según prioridad (costo vs sustentabilidad)

FORMATO: Matriz comparativa con recomendación
```

## 7. Plan de Gestión de Residuos de Construcción

**Nivel:** Intermedio

```
CONTEXTO: Necesito desarrollar un plan de gestión de residuos para cumplir con [LEED MR / requisito local].

INFORMACIÓN DEL PROYECTO:
- Tipo de obra: [nueva/renovación/demolición]
- Superficie: [m²]
- Duración estimada: [meses]
- Meta de desvío: [%]

RESIDUOS PRINCIPALES ESPERADOS:
[Lista de tipos de residuos y cantidades estimadas]

TAREA:
1. Clasificar residuos por tipo y potencial de reciclaje
2. Identificar opciones de desvío para cada tipo
3. Listar instalaciones de reciclaje disponibles localmente
4. Establecer metas de desvío por categoría
5. Diseñar sistema de separación en obra
6. Definir métricas y frecuencia de reporte

FORMATO: Plan de gestión con procedimientos y formatos de seguimiento
```

## 8. Análisis de Ciclo de Vida Simplificado

**Nivel:** Avanzado

```
CONTEXTO: Necesito un análisis de ciclo de vida simplificado para comparar opciones de [SISTEMA/ELEMENTO].

OPCIONES A COMPARAR:
[Listar alternativas con características técnicas]

ALCANCE DEL ANÁLISIS:
- Etapas: [extracción/producción/transporte/uso/fin de vida]
- Período: [años de vida útil]
- Categorías de impacto: [CO2, energía, agua, etc.]

DATOS DISPONIBLES:
[EPDs, factores de emisión, distancias de transporte, etc.]

TAREA:
1. Calcular impacto por etapa del ciclo de vida
2. Comparar opciones en cada categoría
3. Identificar etapa de mayor impacto
4. Calcular diferencia porcentual entre opciones
5. Recomendar opción óptima considerando incertidumbre

FORMATO: Tabla comparativa + gráfico sugerido de resultados

RESTRICCIONES:
- Indicar claramente supuestos utilizados
- Señalar fuentes de datos
- Incluir análisis de sensibilidad si hay datos inciertos
```

## Ejemplos de Uso

### Ejemplo: Análisis LEED

**Input:**
```
Proyecto: Edificio de oficinas corporativas
Ubicación: Ciudad de México
Superficie: 15,000 m²
Objetivo: LEED Gold (60+ puntos)
Estrategias actuales:
- Azotea verde 30%
- Iluminación LED
- Estacionamiento para bicicletas
```

**Output:**
```
## Análisis LEED BD+C v4.1

### Resumen Ejecutivo
Con estrategias actuales: ~45 puntos (Silver)
Para Gold (60 pts): Requiere 15+ puntos adicionales

### Evaluación por Categoría

| Categoría | Disponibles | Estimados | Oportunidad |
|-----------|-------------|-----------|-------------|
| Location & Transport | 16 | 8 | Media |
| Sustainable Sites | 10 | 5 | Alta |
| Water Efficiency | 11 | 4 | Alta |
| Energy & Atmosphere | 33 | 12 | Alta |
| Materials & Resources | 13 | 4 | Media |
| Indoor Environmental | 16 | 8 | Alta |
| Innovation | 6 | 2 | Media |
| Regional Priority | 4 | 2 | Alta |
| **TOTAL** | **110** | **45** | |

### Créditos Recomendados para Gold

| Crédito | Puntos | Costo | Dificultad |
|---------|--------|-------|------------|
| WE: Indoor Water Use | +3 | Bajo | Fácil |
| EA: Optimize Energy | +6 | Medio | Media |
| EQ: Low-Emitting Mat. | +3 | Bajo | Fácil |
| Regional Priority | +2 | Bajo | Fácil |

**Total adicional alcanzable: +14 a +18 puntos**
```
